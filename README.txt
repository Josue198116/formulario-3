FORMULARIO DE PRUEBA - SESION 3

Estructura:
formularios/
├── demo.html
├── controller/demo.php
└── assets/js/bundle/
    ├── demo.js
    └── css/demo.css

Como usarlo con XAMPP:
1. Copia la carpeta "formularios" dentro de C:\xampp\htdocs\azt\
   (debe quedar C:\xampp\htdocs\azt\formularios\demo.html)
2. Inicia Apache desde el panel de XAMPP.
3. Abre en el navegador:
   http://localhost/azt/formularios/demo.html

Si tu Apache usa otro puerto (por ejemplo 89), agrega el puerto:
   http://localhost:89/azt/formularios/demo.html
